# مخطط المذاكرة | Study Planner

أداة تولّد جدول مذاكرة تلقائي حسب المواد وتواريخ الامتحانات وساعات الفراغ، وتصدّر الجلسات إلى Google Calendar.

## المشكلة
توزيع المذاكرة يدوياً قبل الاختبارات يضيع وقت، وغالباً تتكدس المواد الصعبة في آخر لحظة.

## الحل
خوارزمية جدولة تعطي أولوية لكل مادة حسب صعوبتها وقرب امتحانها وعدد الجلسات اللي أخذتها.

## المميزات
- إدخال المواد وتاريخ الامتحان ومستوى الصعوبة
- تحديد ساعات الفراغ لكل يوم
- تنبيه إذا الوقت ما يكفي لمادة
- إضافة الجلسات لـ Google Calendar أو تصدير ملف .ics

## التقنيات
HTML / CSS / JavaScript
